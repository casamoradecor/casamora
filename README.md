## 📌 Sobre o Projeto

O **Casa MORÁ** é um sistema de comércio eletrônico desenvolvido como projeto acadêmico com o objetivo de criar uma loja virtual funcional para venda de produtos de decoração.  

A plataforma permite que os usuários naveguem pelos produtos, visualizem detalhes, adicionem itens ao carrinho de compras e realizem pedidos de forma simples e intuitiva. O projeto busca aplicar conceitos de desenvolvimento web, organização de sistemas e integração de serviços digitais para criar uma experiência de compra online.

## ⚙️ Funcionalidades

O sistema conta com funcionalidades essenciais de uma plataforma de comércio eletrônico:

- Visualização de produtos
- Página de detalhes do produto
- Carrinho de compras
- Cadastro e autenticação de usuários
- Registro de pedidos
- Integração com sistema de pagamento
- Área administrativa para gerenciamento de produtos

---

## 🎓 Objetivo do Projeto

Este projeto foi desenvolvido com fins acadêmicos para aplicar conceitos de desenvolvimento de sistemas web e comércio eletrônico, demonstrando na prática a construção de uma plataforma digital de vendas utilizando tecnologias modernas do ecossistema web.
